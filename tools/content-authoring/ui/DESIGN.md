# Song editor

Build the workspace around two time scales. The overview shows the whole recording and the loop window. The lane editor shows a few seconds at a time and follows the playhead. Keep the selected source and difficulty visible beside it. Put detailed analysis and review notes below the listening controls.

Use a charcoal canvas, warm-white labels, pale green for playback and selection, amber for the playhead, and a distinct per-layer accent. Use tabular figures for time. Keep labels on transport controls and draw from actual waveform and note data. On narrow screens stack the mixer and chart, keeping the same actions available by touch and keyboard.
