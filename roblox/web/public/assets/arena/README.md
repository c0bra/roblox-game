# Arena Runtime Assets

This tree contains only browser-delivery assets approved by a versioned manifest in `roblox/assets/arena_v2/manifests/`.

- `models/`: optimized runtime GLB/glTF assets.
- `textures/`: runtime texture and VFX atlases.
- `audio/`: compressed runtime sound effects.
- `glyphs/`: semantic SVG controls, positions, and attack symbols.
