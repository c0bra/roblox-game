# Arena V2 Asset Workspace

- `source/`: editable originals and license-permitted third-party source files.
- `concept/`: original concept sheets and integration paint-overs.
- `texture/`: editable texture and VFX sources.
- `audio-master/`: generated or edited 48 kHz, 24-bit WAV masters.
- `preview/`: still and motion review outputs.
- `output/`: reproducible intermediate exports before public runtime copying.
- `manifests/`: origin, license, export, checksum, and audio records.

Only files whose manifest permits public browser redistribution are copied to `roblox/web/public/assets/arena/`. Paid or otherwise restricted packages belong in protected external storage and are represented here only by an entitlement reference.
